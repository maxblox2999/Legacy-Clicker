## Use

**Get it:** download the Windows ZIP from [Releases](https://github.com/maxblox2999/Legacy-Clicker/releases), unzip it, and open `Legacy Clicker.exe`.

**Make it click:** your toggle key starts and stops. **Hold mode** clicks while you hold the key. **End** stops automation and editor testing; outside those modes it saves and exits.

**More than one spot?** Add targets, drag them into order, and set delays or repeats. Choose which apps it runs in so it doesn't go clicking where it wasn't invited.
