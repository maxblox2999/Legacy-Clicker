## How to Use

**Download:** Get the Windows ZIP from [Releases](https://github.com/maxblox2999/Legacy-Clicker/releases), extract it, and open `Legacy Clicker.exe`.

**Start clicking:** Press your toggle key to start or stop clicking. **Hold Mode** clicks while you hold the key. The **End** key stops automation and editor testing. Outside those modes, it saves your settings and closes the application.

**Multiple click locations:** Add targets, drag them into the order you want, and set delays or repeats. You can also choose which applications Legacy Clicker is allowed to click in.

A full guide explaining how to use Legacy Clicker and all its features will be published in the future.
