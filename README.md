# Legacy Clicker

A Windows auto-clicker by Max Bonello. The public repository contains release builds and documentation, but no application source code.

The only published build is [v0.1 alpha](https://github.com/maxblox2999/Legacy-Clicker/releases/tag/alpha_0.1). It has automatic clicking and adjustable click settings. Advanced settings have not been fully tested and may fail.

[Download the Windows executable](https://github.com/maxblox2999/Legacy-Clicker/releases/download/alpha_0.1/Legacy.Clicker.exe) from that release. The executable is unsigned, so Windows or antivirus software may warn about it.

Found a bug? [Open an issue](https://github.com/maxblox2999/Legacy-Clicker/issues) with the app version, your Windows version, and steps to reproduce it. For security problems, follow [SECURITY.md](SECURITY.md).
