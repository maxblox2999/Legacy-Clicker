# Changes

## 0.3.0-beta.1

- Centered click speed, animated number changes and ticks, expanding scrollbars, and restored social icons.
- Added coordinate undo/redo, a persistent Add point button, and whole-row drag previews.
- Added a 34-block automation editor with image targets, loops, held input, project files, and a ten-step guide.
- Added recovery for committed changes and a helper that releases recorded held input when the app exits.
- Added manual and optional automatic updates. New releases must have a larger executable; downloads and the executable are checked with SHA-256 before replacement.
- Application source is maintained privately. Actions signs and publishes the compiled Windows package.
